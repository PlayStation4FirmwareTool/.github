## Overview

**GoldHEN (Gold Homebrew Enabler)** is a homebrew-enabling environment for compatible Sony PlayStation 4 consoles. It provides additional system functionality through firmware-specific jailbreak and payload environments.

GoldHEN is one of the main projects in the PS4 homebrew scene. It offers features such as Debug Settings, package installation, FTP access, payload loading, plugin support, external storage support, and additional system utilities.

GoldHEN is not a replacement for the original PlayStation 4 firmware. It relies on a compatible exploit environment and must be used with firmware versions supported by the relevant release.

Compatibility depends on the console's system software version, exploit chain, and GoldHEN build.
